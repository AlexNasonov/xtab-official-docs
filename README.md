# Документация xtab

Официальная документация xtab — платформы таблиц для совместной работы, в облаке и на своём сервере, в том числе без доступа в интернет.

Репозиторий обновляется с каждым выпуском xtab: тег `vX.Y.Z` — документация этой версии, ветка `main` — последней выпущенной. Содержимое собирается автоматически из проверенных материалов выпуска; правки через pull request не принимаются.

## Содержание

- `docs/<язык>/user-guide/` — руководство пользователя: `index.md` с введением и оглавлением, страница на каждый раздел, снимки экрана в `img/` и PDF целиком.
- `docs/<язык>/permissions.md` — матрица прав: что может каждая роль.
- `docs/<язык>/api/openapi.json` — спецификация REST API в формате OpenAPI 3.1.
- `releases/<язык>/` — заметки о релизах: `index.md` с обзором текущей версии и файл на каждую версию.
- `releases/vX.Y.Z.json` и `releases/vX.Y.Z/SHA256SUMS` — сведения о выпуске: офлайн-комплекты по платформам и SBOM с размерами и SHA-256. Комплекты передаются заказчикам при покупке лицензии; суммы здесь — второй, независимый способ проверить, что комплект не изменён: `sha256sum -c SHA256SUMS --ignore-missing` в папке с полученными файлами. Сведения о прошлых выпусках сохраняются.
- `manifest.json` — схема, версия, дата и SHA-256 каждого файла документации (сведения о выпусках в нём не перечислены).

Файлы хранятся байт в байт (`.gitattributes`): Git не меняет концы строк при клонировании, поэтому суммы из `manifest.json` совпадают с файлами на любой системе.

Языки — `ru` и `en`; материала, которого нет на языке, нет и в его папке.

## Устройство (схема 1)

Поле `schema` в `manifest.json` — версия устройства репозитория. Переименование папок, файлов или полей описания страниц меняет схему; добавление новых материалов — нет.

У каждой страницы Markdown в начале описание YAML:

- `title` — заголовок страницы; в тексте страницы заголовка первого уровня нет.
- `description` — краткое описание: первый абзац страницы.
- `version` — версия xtab, `vX.Y.Z`.
- `lang` — язык страницы.
- `order` — у страниц руководств: место в оглавлении, у `index.md` — `0`.
- `date` — у заметок о версии: дата выпуска.

Имена страниц руководств — `NN-название.md`, где `NN` — номер раздела. Ссылки между страницами и на изображения — относительные.
