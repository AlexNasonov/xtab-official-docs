Раздел страницы администратора организации **«Администрирование» → «Политики»**: куда автоматизации могут отправлять запросы и письма. По умолчанию — никуда наружу: письма уходят только участникам организации. Изменения записывает кнопка **«Сохранить»** этого раздела.

- **Разрешённые узлы** — по одному в строке: `api.example.com`, `*.example.com` (все поддомены) или IP-адрес. **Любые узлы** открывают все адреса; для этого нужно ещё раз ввести пароль.
- **Разрешённые адреса писем** — адреса вне организации, которым автоматизации могут писать.

Письма автоматизаций уходят и на **домены приглашений** — их задаёт раздел **«Приглашения»** той же страницы (см. «Политики» в разделе «Администрирование организации»).
