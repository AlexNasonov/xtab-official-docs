Названия функций пишутся по-английски, аргументы — через запятую, поля — в фигурных скобках, тексты — в двойных кавычках. В квадратных скобках — аргументы, которые можно не писать.

**Операторы:**

- `+`, `-`, `*`, `/` — арифметика над числами: `{Цена} * {Количество}`; даты сдвигает функция `DATEADD`;
- `&` — склеивает тексты: `{Название} & " — " & {Количество}`;
- `=`, `!=` (или `<>`), `<`, `<=`, `>`, `>=` — сравнения, дают истину или ложь: `{Цена} > 1000`;
- круглые скобки задают порядок: `({Цена} + 100) * 2`.


Результаты примеров — для записи, где {Название} — «Стол дубовый», {Цена} — 1234.5, {Количество} — 3, {Дата} — 13 марта 2026 года, {Срок} — 20 марта 2026 года 15:30, {Теги} — «Срочно» и «Важно», {Готово} отмечено, {Оценки} — подстановка 4, 5 и 3, {Данные} — текст JSON; сегодня — 16 марта 2026 года, 12:00 по Москве. Числа и даты в результатах записаны без оформления: в таблице они показываются в формате вашего языка.

## Логика и ошибки

| Функция | Что делает | Пример | Результат |
|---|---|---|---|
| `AND(условие1, условие2, …)` | истина, если истинны все условия | `AND({Готово}, {Цена} > 1000)` | `TRUE`, флажок |
| `BLANK()` | пустое значение | `IF({Готово}, BLANK(), {Цена})` | (пусто), число |
| `ERROR([текст])` | значение-ошибка | `IF({Цена} > 1000, ERROR("проверьте цену"), {Цена})` | `#USER`, число |
| `FALSE()` | ложь | `FALSE()` | `FALSE`, флажок |
| `IF(условие, да, [нет])` | одно значение, если условие истинно, другое — если нет | `IF({Цена} > 1000, "дорого", "недорого")` | `дорого`, текст |
| `IFERROR(значение, замена)` | значение, а при ошибке — замена | `IFERROR({Цена} / 0, 0)` | `0`, число |
| `IFS(условие1, значение1, …)` | значение первого истинного условия | `IFS({Количество} > 5, "много", {Количество} > 0, "есть")` | `есть`, текст |
| `ISBLANK(значение)` | истина, если значение пусто | `ISBLANK({Название})` | `FALSE`, флажок |
| `ISERROR(значение)` | истина, если значение — ошибка | `ISERROR({Цена} / 0)` | `TRUE`, флажок |
| `LET(имя1, значение1, …, выражение)` | выражение с именованными промежуточными значениями | `LET(x, {Цена} * 1.2, ROUND(x, 0))` | `1481`, число |
| `NOT(условие)` | истина, если условие ложно | `NOT({Готово})` | `FALSE`, флажок |
| `OR(условие1, условие2, …)` | истина, если истинно хотя бы одно условие | `OR({Количество} > 5, {Готово})` | `TRUE`, флажок |
| `SWITCH(выражение, образец1, результат1, …, [по_умолчанию])` | результат первого образца, равного выражению | `SWITCH({Количество}, 1, "один", 3, "три", "другое")` | `три`, текст |
| `TRUE()` | истина | `TRUE()` | `TRUE`, флажок |
| `XOR(условие1, условие2, …)` | истина, если истинно нечётное число условий | `XOR({Готово}, {Цена} > 1000)` | `FALSE`, флажок |

## Коды ошибок

Если формулу нельзя вычислить для записи, в ячейке показывается код ошибки. Его можно поймать функциями ISERROR и IFERROR.

| Код | Что значит |
|---|---|
| `#DIV_ZERO` | деление на ноль |
| `#VALUE` | значение не того вида: VALUE("abc") |
| `#NUM` | число вне допустимого диапазона или аргумент, который функция не принимает |
| `#TOO_LONG` | текст длиннее, чем может быть длинный текст |
| `#FIELD_DELETED` | поле, которое читает формула, удалено или сменило тип |
| `#USER` | ошибка, которую вернула функция ERROR |
| `#NOT_FOUND` | только в автоматизациях: в ответе шага нет такого пути |


## Функции Excel, которых нет, и чем их заменить

| Функции Excel | Замена |
|---|---|
| `VLOOKUP`, `XLOOKUP`, `INDEX` и `MATCH` | Связь с другой таблицей и подстановка |
| `SUMIF(S)`, `COUNTIF(S)`, `AVERAGEIF(S)` | Сводка по связи с условием **Только связанные записи, где** |
| `RAND`, `RANDBETWEEN` | Нет: значение формулы не должно меняться при каждом пересчёте |
| `INDIRECT`, `OFFSET`, `ROW`, `COLUMN` | Ссылки на поля в фигурных скобках |
| `LAMBDA`, `MAP`, `FILTER`, `SORT` | `LET`, `ARRAYSORT`, сводка по связи с условием |
| `WEBSERVICE` | Автоматизация с шагом «HTTP-запрос» |
| `ISNUMBER`, `ISTEXT` | Не нужны: тип значения проверяется, когда формула сохраняется |
