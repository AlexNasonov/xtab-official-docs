Страница администратора организации (меню учётной записи → **Исходящие адреса**): куда автоматизации могут отправлять запросы и письма. По умолчанию — никуда наружу: письма уходят только участникам организации.

- **Разрешённые узлы** — по одному в строке: `api.example.ru`, `*.example.ru` (все поддомены) или IP-адрес. **Любые узлы** открывают все адреса; для этого нужно ещё раз ввести пароль.
- **Разрешённые адреса писем** — адреса вне организации, которым автоматизации могут писать.
- **Домены приглашений** — домены вашей организации. Управляющие участниками приглашают только с этих доменов. Администратор организации может пригласить и человека с другого домена — например, подрядчика: такой участник становится внешним (см. «Участники»). На эти домены могут уходить письма автоматизаций.
- **Приглашают только администраторы** — новых людей в организацию приглашают только администраторы, а управляющие пространствами и базами выдают роли тем, кто уже в организации.
- **Хранить журнал запусков, дней** — сколько дней хранится журнал запусков автоматизаций, от 7 до 365.
