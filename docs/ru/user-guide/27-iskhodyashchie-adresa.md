Страница администратора организации (меню учётной записи → **Исходящие адреса**): куда автоматизации могут отправлять запросы и письма. По умолчанию — никуда наружу: письма уходят только участникам организации.

- **Разрешённые узлы** — по одному в строке: `api.example.ru`, `*.example.ru` (все поддомены) или IP-адрес. **Любые узлы** открывают все адреса; для этого нужно ещё раз ввести пароль.
- **Разрешённые адреса писем** — адреса вне организации, которым автоматизации могут писать.
- **Домены приглашений** — если заданы, пригласить в организацию можно только адреса этих доменов; на них же могут уходить письма автоматизаций.
