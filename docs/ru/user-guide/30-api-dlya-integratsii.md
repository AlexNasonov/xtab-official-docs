Программы — обмен с 1С, отчёты в BI, свои скрипты — работают с xtab через REST API.

- Получите токен: **меню учётной записи → «API-токены»** (для интеграции лучше служебная учётная запись, см. «API-токены» выше).
- Адрес API — адрес xtab с добавкой `/api/v1`, например `https://xtab.example.ru/api/v1/tables/{таблица}/records`. Описание всех методов — в спецификации OpenAPI из комплекта документации.
- Токен передаётся в заголовке: `Authorization: Bearer xtab_…`. Токен в адресе страницы или в cookie не принимается.
- Токен действует с правами владельца, но только в рамках выбранных разрешений и баз. Если разрешения не хватает, xtab ответит `403` и назовёт его; если токен отозван, истёк или пришёл с чужого адреса — `401`.
- Частота запросов ограничена: по умолчанию 20 в секунду на токен с запасом на 50 подряд. Сверх лимита — ответ `429`; заголовок `Retry-After` говорит, через сколько секунд повторить, а `RateLimit` — сколько запросов ещё можно.
