- **Без лицензии** работает пробный период — 30 дней от первого запуска.
- **Установка лицензии:** панель «Администрирование → Инстанс» (с подтверждением пароля) или команда:

  ```bash
  docker compose run --rm migrate license install /путь/к/файлу.license
  docker compose run --rm migrate license show
  ```

  Лицензия действует на всех узлах без перезапуска. Файл лицензии проверяется подписью поставщика.
- **Когда срок истёк**, 30 дней действует льготный период с напоминанием администраторам. Затем установка переходит в режим «только чтение»: данные читаются, выгружаются и копируются, вход, профиль и администрирование людей работают, изменения данных и запуски автоматизаций — нет.
- **Защита от правки базы.** Состояние лицензии запечатано. Если строку лицензии удалить или поправить в базе, установка тоже переходит в «только чтение», а администраторы видят причину. Исправить — установить действующий файл лицензии, выпущенный не раньше чем за 30 дней.
