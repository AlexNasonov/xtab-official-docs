Xtab ставится одним комплектом без доступа в интернет: образы контейнеров, файлы Docker Compose, установщик и инструкции — внутри архива. Установка — обычный проект Docker Compose в каталоге `/opt/xtab`.

| Сервис | Что делает | Доступ снаружи |
|---|---|---|
| `caddy` | Принимает HTTPS, выдаёт или берёт сертификат, отдаёт приложение | Порты 80 и 443 |
| `xtab` | Узел интерфейса и API: страницы, REST API, realtime | Нет, только через Caddy |
| `xtab-worker` | Узел фоновых задач: импорт и экспорт, пересчёт, автоматизации, письма, резервные копии | Нет |
| `postgres` | PostgreSQL — база данных | Нет |
| `seaweedfs` | Встроенное хранилище файлов с API S3 (можно заменить своим S3) | Нет |
| `backup` | Ночная полная копия базы | Нет |
| `migrate` | Разовый запуск: миграции базы при старте и служебные команды | Нет |

Сети Docker, кроме сети Caddy, внутренние: у узлов Xtab, базы и хранилища нет выхода наружу. Выход для почты и запросов автоматизаций получает только узел фоновых задач и только если вы его включили; если файлы хранятся в вашем S3, выход получают оба узла Xtab, чтобы дойти до него (раздел «Закрытый контур»).
