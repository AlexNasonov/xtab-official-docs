## Настройки инстанса

Страница «Администрирование → Настройки инстанса» и команды `xtab settings` меняют почтовый сервер, лимиты, уровень журналов, правила входа, число фоновых задач и сроки копий сразу на всех узлах, без перезапуска. Рядом с каждым значением показан его источник. Каждое изменение записывается в журнал аудита.

```bash
docker compose run --rm migrate settings get
docker compose run --rm migrate settings set log.level info
docker compose run --rm migrate settings unset log.level
```

Чтобы закрепить настройку на сервере, укажите её в разделе `[pinned]` файла конфигурации, например `"smtp.port" = 2525`: в панели она станет доступна только для чтения.

## Секреты

Секреты задаются только файлами в `secrets/`, в файлах конфигурации их нет: пароли ролей базы, ключи хранилища, пароль почты, главный ключ, ключи аудита и копий. Пароль почтового сервера — файл `secrets/smtp_password`. Сменить пароли ролей базы и ключи встроенного хранилища — `sudo ./install.sh --rotate-secrets`: при сбое возвращаются прежние.

## Вход через Active Directory / LDAP (Keycloak)

На вопрос установщика «Подключить вход через Active Directory / LDAP (Keycloak)?» ответьте «да» (в файле ответов — `keycloak = true` в разделе `[sso]`). Установщик поднимет Keycloak по адресу `https://<домен>/sso/`, заведёт в нём realm `xtab` с клиентом `xtab` и добавит провайдера «Keycloak» в организацию: на странице входа появится кнопка «Войти через Keycloak».

- Консоль Keycloak наружу не публикуется. Откройте её туннелем, например `ssh -L 8180:localhost:8180`, предварительно опубликовав порт `127.0.0.1:8180:8080` сервиса `keycloak` в `docker-compose.override.yml`. Пользователь — `admin`, пароль — в `secrets/keycloak_admin`.
- Каталог организации подключается в консоли: realm `xtab` → «User federation» → LDAP или Active Directory. Группы каталога приходят в утверждении `groups`; на странице «Администрирование → Вход через SSO» их можно связать с группами организации.
- Учётная запись Xtab привязывается к пользователю провайдера, а не к e-mail. Человек с уже существующей учётной записью входит паролем и привязывает провайдера в профиле.
- Вход через провайдера засчитывается вторым фактором администратора. Поэтому настройте в провайдере второй фактор для администраторов Xtab.

Другой провайдер OpenID Connect администратор организации подключает сам на странице «Администрирование → Вход через SSO».
