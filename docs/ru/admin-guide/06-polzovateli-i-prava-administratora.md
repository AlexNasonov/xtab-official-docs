- **Администратор инстанса** управляет лицензией, копиями, настройками инстанса и фоновыми миграциями. Первый администратор получает эти права при установке. Другому администратору организации их выдаёт только консоль сервера:

  ```bash
  docker compose run --rm migrate user instance-admin --email admin2@example.ru
  docker compose run --rm migrate user instance-admin --email admin2@example.ru --revoke
  ```

  Страница «Инстанс» откроется, когда у администратора подключён второй фактор.
- **Когда панель недоступна** или все администраторы потеряли второй фактор, помогает консоль:

  | Команда `docker compose run --rm migrate user …` | Что делает |
  |---|---|
  | `access-link --email <e-mail>` | Одноразовая ссылка: приглашение или сброс пароля (для установки без почты) |
  | `reset-2fa --email <e-mail>` | Снимает все вторые факторы учётной записи и закрывает её сессии |
  | `block` / `unblock` | Блокирует или разблокирует учётную запись: сессии и токены перестают действовать |
  | `unlock` | Снимает блокировку после неудачных входов |
  | `anonymize` | Удаляет учётную запись по просьбе человека: данные выгружаются ему, учётная запись обезличивается |

Команды консоли записываются в журнал аудита с субъектом «консоль» и именем пользователя ОС.
