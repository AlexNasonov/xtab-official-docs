Xtab работает без доступа в интернет: всё, что нужно браузеру, встроено в узел, внешних сервисов и телеметрии разработчику нет.

- **Что выходит наружу по умолчанию:** ничего, кроме Caddy, и только если выбран сертификат Let's Encrypt.
- **Почта и HTTP-запросы автоматизаций** уходят только с узла фоновых задач и только после подключения файла `docker-compose.egress.yml` (установщик подключает его, если вы указали почту). Узел интерфейса почту и запросы автоматизаций не отправляет никогда.
- **Ваше S3:** если файлы хранятся в нём, выход наружу получают оба узла Xtab (`docker-compose.s3.yml`), и обращаются они только к адресу S3 из настроек. Межсетевым экраном хоста разрешите им только этот адрес.
- **Куда можно ходить** решает сам узел: администратор организации задаёт политику «Исходящие адреса» в панели, по умолчанию закрыто всё. Внутренние адреса (частные сети, адреса самой машины) закрыты всегда, кроме перечисленных администратором сервера.
- **Межсетевой экран хоста** рекомендуем настроить так, чтобы машина Xtab не открывала исходящих соединений, кроме нужных вам: почтовый сервер, S3, сервер времени, провайдер входа.
