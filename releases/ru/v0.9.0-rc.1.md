Кандидат версии 0.9 для пилота: исправления по итогам приёмки и внутренней проверки безопасности.

**Улучшения**
- Сетка: меню поля и ячеек открываются правым щелчком, сортировка — из меню заголовка поля; кнопка «Новая запись» поверх сетки; список вариантов открывается вторым щелчком по ячейке; рамки выделения тоньше и мягче.
- Цвета вариантов полей-списков и значение по умолчанию для поля «несколько из списка».
- Редактор длинного текста растягивается за угол и разворачивается в окно записи.
- Сетка перерисовывается быстрее: меньше полных перечитываний, свои правки не применяются повторно, новая высота строк видна сразу, при возврате к таблице строки показываются без ожидания.
- Пространства, базы и таблицы переименовываются и удаляются прямо в интерфейсе; заголовок вкладки браузера называет базу, таблицу и представление.
- Объявление администратора установки: баннер для всех пользователей, в том числе на странице входа, — например, о плановых работах; появляется у всех в течение минуты.
- Почта: проверка почтового сервера при установке, новый пароль почты подхватывается без перезапуска.
- Вход и сессии: не больше 10 одновременных сессий учётной записи (настраивается в политике паролей), новый идентификатор сессии после подтверждения действия, коды восстановления хранятся под ключом установки, второй фактор блокируется после 10 неверных кодов подряд, пароль не может содержать название продукта, организации и своё имя.
- Вход через провайдера засчитывается вторым фактором администратора, только если в настройках провайдера включено «Провайдер подтверждает второй фактор» и провайдер сообщил о нём при входе.
- Защита интерфейса от внедрения скриптов (Trusted Types); запросы к API по HTTP без шифрования отклоняются.
- Подпись журнала аудита вынесена в отдельный сервис `xtab-sealer`; резервные копии и архив аудита подписывает свой ключ `secrets/files_signing_key` (установщик создаёт его при обновлении), подпись копии включает имя файла.
- Метрики узлов отдаются только в отдельной сети Docker `monitoring`: Prometheus подключается к ней (раздел «Мониторинг» инструкции по установке).

**Исправления**
- Установка с почтой: узел интерфейса не запускался без адреса отправителя.
- «Вставить поле слева/справа» добавляло колонку в конец представления.
- Форма поля не давала изменить настройки связи, подстановки и сводки.
- Импорт файла Excel с двумя далёкими ячейками занимал гигабайты памяти.
- Резервные копии не уходили из буфера, когда файлы хранятся в своём S3.
- Удалённая строка лицензии снимала ограничения после перезапуска.
- Проверка журнала аудита засчитывала неподписанные контрольные точки.
- Просроченный пароль менялся без второго фактора.
- Проверка установки отмечала ошибками исправную установку.
