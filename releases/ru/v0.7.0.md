**Улучшения**
- Второй фактор: приложение-аутентификатор с QR-кодом и коды восстановления; passkeys — вход отпечатком, лицом или PIN-кодом без пароля; администраторам организации второй фактор обязателен по политике.
- Вход через провайдера организации по OpenID Connect; Keycloak в поставке для входа через Active Directory и LDAP; группы провайдера управляют группами организации; выход у провайдера завершает сеансы xtab.
- Профиль: фото, имя, часовой пояс, смена пароля и e-mail с подтверждением письмом; свои сеансы с завершением чужих; письмо о входе с нового устройства.
- Политика паролей: длина и состав, запрет повтора, срок действия, блокировка после неверных попыток, проверка по списку утёкших паролей.
- Панель администратора: участники — блокировка, права администратора, завершение сеансов и токенов, сброс второго фактора, снятие блокировки входа; группы, доступ с назначением себе, политики, вход через SSO, матрица прав, настройки организации.
- Журнал аудита: фильтры, выгрузка CSV, цепочка печатей с подписанными контрольными точками и ежедневной проверкой, срок хранения с архивом, выгрузка в SIEM по syslog поверх TLS; встроенные оповещения безопасности с письмами администраторам.
- Удаление учётной записи по запросу человека: доступ прекращается сразу, данные выгружаются в архив, учётная запись обезличивается, а значения в таблицах сохраняются; выгрузка своих данных из профиля.
- Смена главного ключа и ключей организаций командами администратора установки.

**Исправления**
- Вход с кодом восстановления: отправлялся не сам код.
- Вход с passkey предлагает ключи, сохранённые на устройстве.
- Ответ, данный до чтения тела запроса, закрывает соединение.
