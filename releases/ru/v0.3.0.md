**Улучшения**
- Новые типы полей: e-mail, веб-адрес, телефон, валюта, процент, длительность, рейтинг, несколько из списка, пользователь (один или несколько человек).
- Связи между таблицами: связанные записи плашками, выбор из списка с поиском, обратное поле в связанной таблице, вставка связей названиями, фильтр, сортировка и группировка по связи.
- Подстановка, количество связей и сводка по связи с условием на связанные записи — значения обновляются сами, когда меняются связанные записи.
- Формулы: больше сотни функций — арифметика, условия, текст, даты с часовым поясом организации и рабочими днями, списки, регулярные выражения.
  - Подсказки полей и функций при наборе, ошибки сразу на месте, описание аргументов функции, результат на выбранной записи до сохранения.
  - Пересчёт при каждом изменении, в большой таблице — в фоне.
  - Фильтры, сортировка, группировка и итоги по результату формулы; формула может быть первичным полем.
- Первичное поле таблицы можно выбрать в меню поля.
- Вложения: файлы в ячейках — кнопкой или перетаскиванием, миниатюры картинок прямо в таблице, просмотр PDF в окне xtab.
  - При загрузке тип файла проверяется по содержимому.
  - Из фотографий удаляются сведения о месте съёмки, камере и авторе.
  - Убранный из ячейки файл можно вернуть отменой.
- В полях пароля есть кнопка, которая показывает введённый пароль.
- Сгруппированное представление показывает первые записи раньше, чем заголовки групп.

**Исправления**
- Новая связь могла сохранить устаревшую подстановку и сортироваться по старому названию, если связанную запись меняли в тот же момент.
- Фоновая задача по удалённой таблице больше не повторяется до исчерпания попыток.
