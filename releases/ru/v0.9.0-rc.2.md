Второй кандидат версии 0.9: исправления по итогам проверки восстановления на стенде пилота.

**Улучшения**
- Фрагмент настроек Prometheus в комплекте опрашивает и сервис `xtab-sealer`: алерты печати журнала аудита срабатывают.
- `restore.sh` принимает ключ резервных копий по полному пути — например, с отдельного носителя (`--key /media/keys/backup_key`).

**Исправления**
- Восстановление из копии (`restore.sh`) на установке установщиком останавливалось на первом шаге: узел не мог прочитать ключ резервных копий.
- Проверка `xtab doctor` на узле интерфейса показывала порт и защиту почтового сервера по умолчанию вместо настроенных.
