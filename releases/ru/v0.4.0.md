**Улучшения**
- Доступ в интерфейсе: участники и роли пространства и базы, приглашения по e-mail, роли группам, видно, откуда у человека роль.
- Группы пользователей: администратор организации создаёт группы и ведёт их состав.
- API-токены: разрешения, выбор баз, срок действия, разрешённые адреса; показ значения один раз. Служебные учётные записи для интеграций и политика выпуска токенов у администратора.
- Публичный REST API по токену с ограничением частоты запросов; глава руководства об API.
- Длинный текст с форматированием: заголовки, списки, ссылки, цитаты и код; вставка из документов; поиск, фильтры и формулы работают по тексту; при экспорте — разметка Markdown.
- Канбан: карточки в колонках по полю выбора или пользователя, перетаскивание мышью и касанием, перемещение с клавиатуры, новая карточка в колонке, изменения других людей сразу.
- Формы: конструктор с обязательными вопросами и условиями показа, заполнение участниками базы, публичная ссылка без входа с защитой от роботов, отзыв ссылки; вопросы о файлах и людях.
- Установщик комплекта: проверка машины, вопросы или файл ответов (пример со всеми ключами — в комплекте), своё хранилище S3, проверка работы после запуска, первая организация; обновление с копией базы и откатом при сбое, восстановление базы из копии, установка Docker из репозиториев ОС.
- `xtab doctor` проверяет хранилище файлов пробной записью.
- Стандартное отклонение по спискам значений подстановки.

**Исправления**
- По итогам проверки безопасности: хранилище файлов — в отдельной сети, его служебные HTTP-API выключены, доступ к томам подписан; ужесточены контейнеры PostgreSQL и хранилища; заголовок `X-Request-Id` принимается только от прокси; ограничен размер картинок для миниатюр.
