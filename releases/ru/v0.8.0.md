**Улучшения**
- Смена типа поля с переносом данных: предпросмотр результата, перенос в фоне, старые значения сохраняются до проверки.
- Значение по умолчанию и проверка ввода для полей.
- Внешние участники: подрядчика с чужого домена можно пригласить, он помечается как внешний; политика «Приглашают только администраторы».
- Список импортов с отменой в течение суток; срок хранения журнала запусков автоматизаций в политике организации.
- Лицензия установки: пробный период 30 дней, установка ключа командой администратора, баннер о сроке, режим «только чтение» без действующей лицензии.
- Резервное копирование: непрерывный архив журнала базы и ночные копии, зашифрованные открытым ключом; копии файлов; восстановление на любой момент одной командой; еженедельное учение восстановления с замером времени.
- Панель администратора установки: лицензия, резервные копии и учения, настройки без перезапуска, фоновые миграции, оповещения.
- Перенос и обслуживание: перенос файлов между хранилищами, внешняя СУБД, удаление установки, смена паролей служб.
- Наблюдаемость: дашборды и правила оповещений, каталог метрик, трассировка запросов, метрики браузера.
- Быстрые сортировки: индексы для часто используемых сортировок создаются сами.
- Доступность: экранный диктор называет активную ячейку, сетка следует размеру шрифта браузера и масштабу 200 %.
- Закрытый контур: сборка без интернета, воспроизводимая сборка, страница «О программе» с лицензиями компонентов, предупреждения при недоступности хранилища или почты.
- Память базы данных подбирается по машине: кэш PostgreSQL — четверть памяти сервера.
- Подтверждено на стенде заказчика: 500 одновременных пользователей — чтение и запись записи за 15–25 мс, правка видна другим за 0,15 с (p95); обновление под нагрузкой — около 8 секунд простоя.

**Исправления**
- Вход: успешные входы больше не расходуют лимит попыток — офис за одним адресом входит без отказов.
- Узлы держат соединения 500 человек: поднят предел открытых файлов.
- Установщик проверяет бакет резервных копий в своём S3.
- Лист Excel с огромным диапазоном отклоняется до чтения.
- После завершения сеанса форма входа создаётся один раз и не теряет ввод.
- Состояние лицензии не меняется правкой базы в обход сервера.
