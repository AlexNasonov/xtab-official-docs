**Improvements**
- Interfaces of a base: a builder of apps from pages and ready elements — grid, list, kanban, record card, fields of a new record, number, text, button and filter; layouts «Dashboard», «List and card», «Form» and «Blank canvas»; elements are rearranged by dragging; a draft and its publication.
- An element shows only the fields chosen and lets change only those marked; its required filter, «the current user» included, is neither seen nor lifted by its users; creating, changing and deleting records as the element allows.
- Buttons of interfaces: create a record, change the chosen record, open an address with the values of the record, start an automation; a new automation trigger «A button is pressed».
- Access to a single interface without access to its base, to view or to work; a section «Interfaces» on the start page.
- Changes of other people in the elements of an interface show at once.
- A copy of a base copies its interfaces, unpublished and given to nobody.
- The app opens faster: the interface builder and the automation editor load only when opened.
- Editing a record with formulas is faster: simple formulas are counted with the edit itself.

**Fixes**
- The settings of a view are kept after a field they used is deleted.
- The list of a multiple select closes when another cell is chosen.
