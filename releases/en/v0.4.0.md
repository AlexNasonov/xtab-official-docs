**Improvements**
- Access in the interface: members and roles of workspaces and bases, invitations by email, roles of groups, where a person's role comes from.
- User groups: the administrator of the organization creates groups and keeps their members.
- API tokens: permissions, chosen bases, expiry, allowed addresses; the value shown once. Service accounts for integrations and a token policy for the administrator.
- Public REST API by token with rate limits; a chapter of the guide on the API.
- Rich text: headings, lists, links, quotes and code; pasting from documents; search, filters and formulas work on the text; Markdown on export.
- Kanban: cards in stacks by a select or user field, dragging with the mouse and by touch, moving with the keyboard, a new card in a stack, changes of other people at once.
- Forms: a builder with required questions and conditions, filling in by the members of the base, a public link without signing in protected from robots, revoking the link; questions about files and people.
- The installer of the bundle: a check of the machine, questions or a file of answers (an example with every key comes in the bundle), your own S3 storage, a health check after start, the first organization; an update with a copy of the database and a rollback on failure, restoring the database from a copy, installing Docker from the repositories of the OS.
- `xtab doctor` checks the file storage with a probe object.
- Standard deviation over lists of lookup values.

**Fixes**
- After the security review: the file storage is in a network of its own, its service HTTP APIs are off, access to its volumes is signed; the PostgreSQL and storage containers are hardened; the `X-Request-Id` header is taken from the proxy only; the size of images for thumbnails is limited.
